# Dosa Balkon

Балконды әйнектеу, демонтаж, терезе мен шкаф орнату және утепление қызметтеріне арналған бір беттік сайт.
Қазақша және орысша тілдер ауыстырылады. Өтінім формасы дайын хабарламаны WhatsApp-та ашады.

## Құрылымы

```
index.html        бет
css/style.css     стильдер
js/main.js        тіл ауыстыру және WhatsApp сілтемесі
images/           жобалардың фотолары
```

Құрастыру қадамы жоқ, бұл қарапайым статикалық сайт. `index.html` файлын браузерде ашсаңыз жеткілікті.

## GitHub Pages арқылы жариялау

1. GitHub-та жаңа репозиторий жасаңыз, мысалы `dosa-balkon`.
2. Осы папканың ішіндегі барлық файлды репозиторийге жүктеңіз.
3. Repository → Settings → Pages бөліміне өтіңіз.
4. Source: `Deploy from a branch`, Branch: `main`, папка: `/ (root)` таңдап, Save басыңыз.
5. Бір-екі минуттан кейін сайт `https://<аккаунт>.github.io/dosa-balkon/` мекенжайында ашылады.
